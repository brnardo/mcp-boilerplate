Meta Ads Reporting for MCP

Login with Google or GitHub, unlock paid tiers with Stripe, and stream Meta Ads insights straight into your MCP-compatible assistant.

This worker ships with the same analytics entry points as the pipeboard-co/meta-ads-mcp reference server:

  • Account overview – free summaries of spend, reach, and balance.
  • Campaign & ad set insights – subscription-gated performance breakdowns.
  • Ad-level analytics – metered usage that charges after the free tier.
  • Async report status – monitor long-running exports in real time.

Configure your Meta Business system user token, default ad account, and Stripe price IDs in .dev.vars to start streaming reports.

Need help? Check the README for full setup instructions.
